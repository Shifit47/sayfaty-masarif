# سيفتي — ميزانية الشباب

تطبيق موبايل بسيط (أندرويد) لإدارة مصاريف الشريكين والأصدقاء المغتربين.

## المميزات
- إدخال سريع للمصاريف (مشترك / فردي) مع قوائم منسدلة
- أعضاء + عهد (مبلغ مقدّم)
- تسويات (تحويلات فعلية بين الأعضاء)
- ملخص تلقائي: الرصيد النهائي لكل عضو + مين يستحق من مين
- التخزين محلياً على الجهاز — بدون حسابات، بدون إنترنت

## التشغيل محلياً (للاختبار)
```
pip install -r requirements.txt
python main.py
```

## بناء APK في السحابة
اعمل push إلى فرع `main` — GitHub Actions يبني APK تلقائياً.
نزّل الـ APK من تبويب **Actions** → أخر تشغيل → الرطبب **sayfaty-arm64**.

## بنية الملفات
- `main.py` — واجهة Flet (4 شاشات: مصاريف، أعضاء، تسويات، ملخص)
- `storage.py` — قاعدة بيانات SQLite محلية + كل حسابات الرصيد
